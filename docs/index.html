Install

Drop this in your Claude Desktop config.

Edits ~/Library/Application Support/Claude/claude_desktop_config.json on macOS, %APPDATA%\Claude\claude_desktop_config.json on Windows. Restart Claude Desktop and you're done.

// Free hosted endpoint — 30 requests / IP / hour. No install, no API keys.
{
  "mcpServers": {
    "black-book": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://black-book-host.vercel.app/mcp"]
    }
  }
}
// Run the MCP server locally — unlimited usage, no rate limit.
// First clone the repo:
//   git clone https://github.com/lswank/black-book ~/code/black-book
//   cd ~/code/black-book/mcp && npm install
{
  "mcpServers": {
    "black-book": {
      "command": "node",
      "args": ["/Users/YOUR_USERNAME/code/black-book/mcp/server.mjs"]
    }
  }
}

9 frameworks

Pick a shape, get a prompt.

Each framework is a tool you can call directly. Pipe in what you want; the server returns a structured, copy-pastable prompt template with the missing inputs surfaced.

T · A · G

apply_framework("T-A-G", …)

Task · Action · Goal

Quick ad-hoc requests where you know what you want done.

B · A · B

apply_framework("B-A-B", …)

Before · After · Bridge

Cold outreach, problem/solution copy, turnaround narratives.

R · T · F

apply_framework("R-T-F", …)

Role · Task · Format

Short, structured outputs — ad copy, headlines, social posts.

C · A · R · E

apply_framework("C-A-R-E", …)

Context · Action · Result · Example

Grounded work — landing pages, longer content with brand voice.

R · I · S · E

apply_framework("R-I-S-E", …)

Role · Input · Steps · Expectation

Multi-step long outputs — full posts, scripts, sequences.

A · I · M

apply_framework("A-I-M", …)

Strategy — channels, OKRs, growth loops, market entry.

G · R · O

apply_framework("G-R-O", …)

Goal · Reason · Output

Lightweight planning — newsletters, calendars, briefs.

F · I · T

apply_framework("F-I-T", …)

Format · Input · Task

Transforms — press releases, meta tags, summaries.

L · E · D

apply_framework("L-E-D", …)

Calibration — when the same content could be written ten ways.

how it works

Three primitives, infinite combinations.

01

Specialists

Each specialist is a hand-tuned persona. Subagents (artifact producers) return drafts; skills (consultative) load as the conversation persona. Call get_specialist to load one.

02

Frameworks

Nine intake patterns that turn vague asks into well-formed prompts. Use apply_framework directly, or let prompt_bank pick the right one for your task.

03

Workflows

Pre-built chains for end-to-end work — launch, hire, board update, fundraise, churn recovery. Call flow with a scenario name and run the chain.
