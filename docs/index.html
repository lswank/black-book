9 frameworks

Pick a shape, get a prompt.

Each framework is a slash command. Pipe in what you want; get back a structured, copy-pastable prompt with the missing inputs surfaced.

T · A · G

/tag

Task · Action · Goal

Quick ad-hoc requests where you know what you want done.

B · A · B

/bab

Before · After · Bridge

Cold outreach, problem/solution copy, turnaround narratives.

R · T · F

/rtf

Role · Task · Format

Short, structured outputs — ad copy, headlines, social posts.

C · A · R · E

/care

Context · Action · Result · Example

Grounded work — landing pages, longer content with brand voice.

R · I · S · E

/rise

Role · Input · Steps · Expectation

Multi-step long outputs — full posts, scripts, sequences.

A · I · M

/aim

Action · Intent · Metric

Strategy — channels, OKRs, growth loops, market entry.

G · R · O

/gro

Goal · Reason · Output

Lightweight planning — newsletters, calendars, briefs.

F · I · T

/fit

Format · Input · Task

Transforms — press releases, meta tags, summaries.

L · E · D

/led

Level · Expectation · Direction

Calibration — when the same content could be written ten ways. Read why →

on demand

The prompt bank that doesn't go stale.

Static prompt libraries are a 2023 artifact — Claude already produces tailored prompts better than a 1,000-prompt PDF.

/prompt-bank linkedin post launching v2 of our SOC 2 product

→ Picks social-post-writer, applies R-T-F, asks for the missing audience and CTA, then emits the finished prompt and offers to run it.

orchestration

Chain specialists for end-to-end work.

/flow ships with 13 pre-built scenarios. Skills lead with strategy; subagents follow with artifacts; outputs feed forward through the chain.

positioning-coach → landing-page-copywriter → seo-meta-writer → social-post-writer → ad-copywriter → press-release-writer

/flow postmortem-loop

crisis-comms-coach → postmortem-writer → exec-comms-writer → decision-memo-writer

/flow okr-cycle

strategy-coach → chief-of-staff-advisor → okr-writer → all-hands-talking-points-writer

/flow fundraise

fundraise-narrative-coach → vision-memo-writer → demo-deck-writer → investor-update-writer

/flow content-engine

content-strategist → blog-post-writer → seo-meta-writer → social-post-writer → newsletter-writer

/flow prd-loop

/flow migration
