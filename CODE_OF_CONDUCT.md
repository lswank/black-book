# Code of Conduct

This project follows a short, practical code of conduct.

## Expected behavior

- Be direct, technical, and respectful. Assume good faith.
- Argue with the work, not the person. Disagreement is welcome; ad hominem isn't.
- When you correct someone, point at what's wrong and what'd be better — don't just declare it.
- If a contribution doesn't fit, say so plainly with the reason.

## Unacceptable behavior

- Personal attacks, harassment, slurs, or sustained disruption.
- Sexualized language or imagery.
- Publishing other contributors' private information without permission.
- Bad-faith arguing for the sake of arguing.

## Enforcement

Project maintainers may remove contributions, comments, or contributors who violate these rules. Egregious or repeated behavior results in a permanent ban from the project.

## Reporting

Report concerns by opening a private issue or contacting the maintainer directly. Reports are reviewed and acted on as quickly as possible. Reporters' identities are kept confidential when requested.
